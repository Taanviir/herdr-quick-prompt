# Quick Prompt has moved

Quick Prompt now lives in [Taanviir/my-herdr-plugins](https://github.com/Taanviir/my-herdr-plugins/tree/main/quick-prompt),
with the other Herdr plugins. This repo is archived.

To switch an existing install:

```bash
herdr plugin uninstall taanviir.quick-prompt
herdr plugin install Taanviir/my-herdr-plugins/quick-prompt
```

Your settings, key bindings and saved state stay where they are.
